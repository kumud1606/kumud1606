# Setup

## 1. Create the special repo
Repo name must exactly match your username: `kumud1606/kumud1606`, public, with a README.

## 2. Add these files
Copy everything here into that repo, keeping the folder structure:

```
kumud1606/
├── README.md
├── info-card.svg          (already generated, ready to use)
├── ascii-portrait.svg      ← you generate this, see step 3
├── contrib-heatmap.svg     ← generated by the Action on first run
├── requirements.txt
├── scripts/
│   ├── generate_ascii.py
│   ├── generate_info_card.py
│   └── generate_heatmap.py
└── .github/workflows/update.yml
```

## 3. Generate your ASCII portrait (one-time, local)
This is the one piece that needs a real photo of you, so it's not automated:

```bash
pip install -r requirements.txt
python scripts/generate_ascii.py --input your-photo.jpg --output ascii-portrait.svg
```
Use a clear, front-facing, decent-contrast photo — square crops work best. Commit the resulting `ascii-portrait.svg`.

## 4. Push it
```bash
git add .
git commit -m "profile: initial setup"
git push
```

## 5. Let the Action take over
`.github/workflows/update.yml` runs daily and on manual trigger (Actions tab → "Update Profile" → "Run workflow"). It regenerates:
- `contrib-heatmap.svg` — real contribution data pulled live via GitHub's GraphQL API
- `info-card.svg` — same info card (regenerated for consistency; edit the constants at the top of `generate_info_card.py` any time your bio changes)

No extra secrets needed — the default `GITHUB_TOKEN` GitHub provides to Actions is enough to read your own public contribution calendar.

## Customizing
- **Colors/theme**: edit the `GREEN` / `BG` constants at the top of each script in `scripts/`.
- **Status lines** on the info card: edit `STATUS_LINES` in `scripts/generate_info_card.py`.
- **Pinned projects** in the README: just swap the table entries for whatever you want to feature.
